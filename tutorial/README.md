# 小红书视频下载器 · 源码级分步教程

> 这不是一份“命令速查表”，而是一条**跟着源码走的学习路径**。
> 读完这 8 篇，你应该能做到：自己改一个提取规则、自己加一个 GUI 按钮、自己在另一台机器上打出可用安装包。

---

## 合规边界（先读，30 秒）

本工具仅限下载**你自己的账号**或**已获得作者明确授权**的视频，用于个人备份、学习与研究。
请勿用于批量搬运、二次分发或任何商业用途。教程中的示例链接均为占位符，不要用来实际访问他人内容。

## 每篇的结构

每篇都遵循同一个节奏：

1. **这一篇解决什么问题** —— 先明确目标
2. **源码导读** —— 按真实代码路径讲，附行号与片段
3. **动手实验** —— 一个小改动或小验证，把知识钉死
4. **小结 / 自检题** —— 确认你真的理解了

---

## 开始之前

你需要：

- Python 3.10+（项目实测 3.11.9）
- 一点点 `async/await` 基础（知道 `await` 是在等 I/O 就够了）
- 会用浏览器 DevTools 看 Network 和 Console

不需要：前端构建工具、C++ 编译器、任何付费服务。GUI 用的是原生 HTML/CSS/JS，**没有 npm 步骤**。

---

## 项目一句话架构

```
CLI ──┐
      ├──► JobConfig ──► run_job() ──► 浏览器会话 ──► 列表收集 ──► 详情解析 ──► 并发下载 ──► state.json
GUI ──┘                     ↑ 日志/进度/二维码/取消 全部走可选回调
```

这条链路会在后面反复出现。先记住它，后面每篇都是在给某一环做放大。
